# FaraiConnect

FaraiConnect is a Zimbabwe-focused place and property network for verified property discovery, local places, and memories tied to real locations.

## Current MVP

- Static login and registration page
- FaraiConnect SVG logo and icon mark
- Login with Gmail placeholder
- Login with username, email, or phone placeholder
- Registration fields for first name, last name, username, email or phone, date of birth, and sex

## Local Preview

Open `frontend/index.html` in a browser.

## Netlify Setup Later

Use `frontend` as the publish directory for the static site.
